# Mentor – One-to-One Guidance

Professional One-to-One mentorship module for VKS Tech.  
**Firebase:** Same project as Man Power (`metpowervks`)

## Deploy (same repo as Man Power / website)

Upload the `Mentor` folder into:

| Host | Path |
|------|------|
| **manpower.vkstech.com** | `/Mentor/` (next to `js/`, `MR_Skill/`, etc.) |
| **vkstech.com** | `/Mentor/` (next to `index.html`) |

Main file: `Mentor/mentor.html`

Learn & Grow in Man Power opens: `/Mentor/mentor.html`  
Website page: `mentor.html` embeds `Mentor/mentor.html`

## Firebase paths
- `mentor_guidance/{mobile}`
- `mentor_guidance_index/{mobile}`

**Required:** Redeploy Man Power `database.rules.json` (includes Mentor rules) in Firebase Console.
