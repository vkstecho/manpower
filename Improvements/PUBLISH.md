# Publish to GitHub

1. Unzip `ManPower-v4.0.3-github.zip`
2. Copy everything inside `ManPower-v4.0.1/` into your repo root:  
   https://github.com/vkstecho/manpower
3. Commit and push
4. Deploy hosting as usual
5. In the live app: Admin → Payment settings → set amounts → **Seed annual from current monthly amounts** → Save → **Publish to landing page**
