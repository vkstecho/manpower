📌 Team Excel format (snapshot guide)
Row 1 = headers. Example — same style as your sheet:
Name Emp ID Designation Weekly Off Mobile Joining Date Date of Birth Machine Responsibility Salary
DINESH 50000555 Team Member TUE 9695887766 23-09-2024 01-01-1994 M-1 Operation 25000
SURAJ 50000556 Team Member WED 7408920675 01-09-2025 01-01-1994 M-1 Operation 48000
Required: Name, Emp ID
Recommended columns (in order): Name, Emp ID, Designation, Weekly Off, Mobile, Section (required for section-wise Home), Machine, Responsibility, Salary, Joining Date, Date of Birth
Optional: Joining Date, Date of Birth, Salary (numbers only)
Emp ID से match → existing update · खाली cell = पुराना data रहेगा
Shift date columns (01-Jul-25 …) इस Team upload में ignore होते हैं — shifts के लिए Schedule Excel upload use करें।
