Quick lesson 1 — Yield %

In a production log, if B2 = good output (kg) and C2 = input (kg):

=IF(C2=0,"",B2/C2)

Format as Percentage. Copy down the column for each shift/day.

Quick lesson 2 — Waste kg 
=C2-B2

Then pivot by machine or shift to find the biggest loss area.

Quick lesson 3 — Shift roster count

If codes D/N/O are in row of a person, count day shift heads for Monday (column C):

=COUNTIF(C:C,"D")

Use the same for N. Compare to required manpower for coverage.
