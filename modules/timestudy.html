Quick lesson 1 — Define the element

Split the job: setup → run → unload. Time each element 5–10 cycles. Drop the obvious outlier.

Quick lesson 2 — Average & target 
Average cycle (sec) = SUM(times) / N
Pieces per hour ≈ 3600 / average_sec

Compare to current plan. Gap = coaching or process change.
